二维码分享 / 识别

将加密密文转换为二维码，或从本地图片中识别二维码。二维码不会包含密码。

生成和识别过程均不发送网络请求。建议密文较短时使用二维码。
二维码识别使用浏览器内置 BarcodeDetector：目前主要在 Chrome / Edge 的部分版本和环境中可用；不支持时会提示。密码请通过其他渠道发送。
加密格式：OFFLINE-ENC-V1: + Base64(JSON)，包括随机盐、随机 IV 和密文；PBKDF2-SHA-256（600,000 次迭代）派生 256 位 AES-GCM 密钥。每次加密随机生成盐和 IV，使用浏览器内置 Web Crypto API。密文暴露后仍可能遭受离线密码猜测，请使用高强度密码。请仅用可信来源的原始文件，避免运行不明修改版本。
